# Stealth Puyo

Windows / PyQt5 단일 파일 뿌요뿌요. **숨기기**를 중심으로 만든 앱입니다.

같은 저자의 `txt viewer`(Stealth TXT Reader)에서 은폐 구조 — 전역 핫키 숨김,
배경 지우기, 위장 창, 트레이 상주 — 를 그대로 이어받고, 게임 부분만 최신
뿌요뿌요 규칙으로 새로 만들었습니다.

```bash
pip install PyQt5
```

```bash
python stealth_puyo.py
```

## 1. 숨기기 (핵심)

| 상황 | 방법 |
|---|---|
| 즉시 숨기기 | `Esc` — 창이 사라지고 판은 그대로 얼어붙는다 |
| 어디서든 숨기기 / 복귀 | `Ctrl+Alt+Z` — 다른 프로그램을 쓰는 중에도 동작하는 전역 핫키 |
| 배경 지우기 | `Ctrl+B` / `Ctrl+Alt+B` — 창 배경이 완전히 사라지고 뿌요만 화면에 뜬다 |
| 빠른 재시작 | `R` 또는 `F2`, 어디서든 `Ctrl+Alt+F2` — 확인 없이 즉시 새 판 |
| 다른 창을 보면서 플레이 | `Ctrl+Alt+←→↓↑`, `Ctrl+Alt+Enter` 전역 조작키 |
| 창 자체를 감추기 | 설정 → 창 모드 `숨은 창` — 작업 표시줄·Alt+Tab 목록에서 빠진다 |
| 다른 이름으로 위장 | 설정 → 창 모드 `위장 창` + 위장 제목(기본 "메모장") |
| 포커스를 잃으면 자동 숨김 | 설정 → 화면 → "포커스를 잃으면 자동으로 숨기기" |
| 트레이에서 꺼내기 | 트레이 아이콘 클릭 (툴팁에 등록된 전역 키 목록이 나온다) |
| 종료 | `Ctrl+Alt+Q` 또는 트레이 → 종료. 창 닫기(`X`)는 종료가 아니라 숨기기 |

동작 방식

- **전역 핫키** — `RegisterHotKey` 로 OS에 직접 등록하고 `WM_HOTKEY` 를
  네이티브 이벤트 필터에서 받는다. 창이 포커스를 갖고 있지 않아도 동작한다.
  수식키(Ctrl/Alt/Shift/Win) 없는 조합은 위험해서 등록을 거부한다.
- **배경 지우기** — 테두리 없는 창에 `WA_TranslucentBackground` 를 켜고
  배경을 직접 칠한다. 배경 알파를 `0` 으로 내리면 아무것도 칠하지 않아
  뒤쪽 창의 글자가 그대로 보이고 뿌요만 공중에 뜬다.
- **숨길 때 자동 일시정지**(기본 켜짐) — 숨긴 사이에 판이 진행되어 게임
  오버가 되는 일이 없다. 복귀하면 `P` 로 재개. 숨어 있는 동안
  `Ctrl+Alt+F2` 로 재시작해도 판은 얼린 채로 둔다.
- **전역 키가 이미 쓰이고 있으면** 등록에 실패한다. 어떤 키가 실패했는지
  트레이 툴팁과 상단바에 알려 주니, 설정 → 단축키에서 다른 조합으로 바꾸면 된다.
  (예: `Ctrl+Alt+R` 은 다른 프로그램이 자주 선점해서 기본값에서 뺐다.)

## 2. 게임 규칙 (최신 뿌요뿌요 계열)

- **필드** 6열 × 12줄 + 숨은 13번째 줄. 숨은 줄의 뿌요는 터지지 않는다.
- **게임 오버** 3열(가운데 왼쪽) 숨은 줄이 막히면 종료 — 본가와 같은 판정.
- **조** 축뿌요 + 자뿌요. 자뿌요가 축뿌요를 돌며 회전한다.
- **회전 보정** 벽 밀기(벽에서 돌리면 축이 밀린다), 바닥 밀기(바닥에서
  아래로 돌리면 축이 한 칸 뜬다), **퀵턴**(좌우가 모두 막히면 180도 뒤집기).
- **굳기 지연** 바닥에 닿아도 0.42초 여유가 있고, 이동·회전하면 초기화된다.
- **중력** 굳힌 직후 · 터진 직후 · 방해뿌요가 쏟아진 직후에는 떠 있는 뿌요가
  가속을 받으며 실제로 떨어지고(`drop` 단계), **낙하가 완전히 끝난 뒤에만**
  다음 터짐을 판정한다. 그래서 연쇄가 한 단계씩 눈에 보인다.
- **점수** 본가 공식 `10 × 지운 개수 × (연쇄 + 색 + 덩어리 보너스)`
  - 연쇄 보너스 0, 8, 16, 32, 64, 96, … (19연쇄 이후 32씩)
  - 색 보너스 1색 0 / 2색 3 / 3색 6 / 4색 12 / 5색 24
  - 덩어리 보너스 4개 0 … 10개 7 / 11개 이상 10
- **전체 지우기** 판을 비우면 +2100.
- **방해뿌요** 색 덩어리를 만들지 않고, 옆에서 뿌요가 터지면 함께 사라진다.
  천장에서 한꺼번에 쏟아지며 한 번에 최대 30개(5줄)까지 떨어진다.
- **상쇄** 번 점수를 목표 점수(기본 70)로 나눈 수만큼 예고 방해뿌요를 지우고,
  남으면 밖으로 보낸다(전송 표시).
- **마진 타임** 96초 이후 16초마다 목표 점수가 내려가 방해뿌요가 무거워진다.
- **NEXT 2조**, 착지 위치 표시, 연쇄 수 표시, 첫 3조는 3색으로 제한.
- **속도** 15조마다 레벨이 올라 낙하가 빨라진다(최대 20레벨).

### 모드

- **엔드리스** — 혼자 연쇄를 쌓는 연습판.
- **방해뿌요** — 레벨에 따라 일정 간격으로 방해뿌요가 쏟아진다. 연쇄로 상쇄한다.

## 3. 기본 조작

```
← →      이동
↓        빠르게 낙하 (바닥에서 누르면 바로 굳는다)
↑ / X    시계 방향 회전
Z        반시계 방향 회전
Space    즉시 낙하
P        일시정지
R / F2   빠른 재시작 (일시정지·게임 오버 중에도 바로 먹는다)
F1       설정
Ctrl+R   메뉴 (창 아무 곳에서 우클릭해도 열린다)
```

전역 — 다른 창을 쓰는 중에도 동작

```
Ctrl+Alt+Z       숨기기 / 복귀
Ctrl+Alt+F2      빠른 재시작
Ctrl+Alt+B       배경 지우기
Ctrl+Alt+P       일시정지
Ctrl+Alt+← →     이동
Ctrl+Alt+↓       빠르게 낙하
Ctrl+Alt+↑       시계 방향 회전
Ctrl+Alt+Enter   즉시 낙하
Ctrl+Alt+Q       종료
```

화면

```
Ctrl+B        배경 지우기 토글
Ctrl+[ / ]    창 투명도 (마우스 휠로도 조절)
Ctrl+↑ / ↓    셀 크기 (12~48px — 창 크기가 여기서 결정된다)
Ctrl+T        항상 위
Ctrl+H        사이드 패널
Ctrl+J        상단바
```

단축키는 전부 설정 → 단축키 탭에서 바꿀 수 있다. 비워 두면 그 동작은 꺼진다.
창은 아무 곳이나 끌어서 옮긴다. 상단바 아이콘은 왼쪽부터 재시작 · 설정 ·
숨기기이고, 각각 설정에서 숨길 수 있다.

## 4. 설정 저장

`%APPDATA%\StealthPuyo\config.json` — 화면·게임 설정, 단축키, 최고 점수와
최고 연쇄, 창 위치. 임시 파일에 쓰고 교체하므로 도중에 죽어도 깨지지 않는다.

같은 앱을 두 번 실행하면 새 창이 아니라 이미 떠 있는 창이 나온다(단일 인스턴스).

## 5. exe 빌드

```bash
build.bat
```

`dist` 폴더에 `Notepad.exe` 가 만들어진다. 콘솔 창 없는 단일 파일이다.

빌드 설정은 `Notepad.spec` 에 있다. 이 앱이 쓰지 않는 Qt 모듈(소프트웨어
OpenGL 21MB, QML/Quick, OpenSSL)을 걷어내 40MB → 24MB 로 줄여 둔 것이니,
실행에 문제가 생기면 spec 의 `DROP_BINARIES` 를 빈 목록으로 두고 다시 빌드하면
원래대로 돌아온다.

```bash
python -m PyInstaller --noconfirm Notepad.spec
```

실행 파일 이름은 spec 의 `name` 값으로 바꾼다.

## 6. 코드 구조

| 위치 | 내용 |
|---|---|
| `seq_to_win`, `HotkeyFilter`, `HotkeyManager` | 전역 핫키 등록/수신 |
| `Config` | 설정 저장/복원 |
| `PuyoGame` | 화면과 무관한 순수 게임 규칙 (상태 기계) |
| `BoardWidget`, `NextWidget` | 필드와 NEXT 그리기 |
| `SettingsDialog` | 화면 / 게임 / 단축키 탭 |
| `PuyoWindow` | 창, 은폐 동작, 입력, 트레이 |

`PuyoGame` 은 Qt에 의존하지 않아 규칙만 따로 시험할 수 있다.
